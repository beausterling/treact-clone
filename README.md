# Treact Clone

A clone of the Treact landing page, built for the final project of Module 3 of my web dev course.

Live site: https://beausterling.github.io/treact-clone/

## What's on the page

- Nav bar with hover underlines and a slide-in mobile menu
- Hero section with an email sign up input
- Features, quality work, steps and values sections
- Pricing cards (each card's colors come from `nth-child`)
- Testimonial, call to action banner and footer

## Built with

- HTML
- CSS (Flexbox, media queries)
- A little JavaScript to open and close the mobile menu

I built the desktop layout first, then added media queries at 1280px, 1024px, 768px and 640px to make it responsive. The FAQ (accordion) section from the original site was out of scope for this project.

## Run it locally

Clone the repo and open `index.html` in your browser, or use the Live Server extension in VS Code.
